# 预览页使用说明（给审核人 / 维护者）

## 一、如何查看预览

```bash
# 在仓库根目录
npm install
npm run dev
```

浏览器访问：

```
http://localhost:5173/MCTP-Frontend/#/preview
```

> 注意 `#/preview` 是 hash 路由；`base` 已在 `vite.config.js` 配为 `/MCTP-Frontend/`。

## 二、如何验证生产构建（GitHub Pages 兼容性）

```bash
npm run build      # 产物在 dist/
npm run preview    # 本地模拟生产构建
```

访问：`http://localhost:4173/MCTP-Frontend/#/preview`

`dist/index.html` 中资源路径均为 `/MCTP-Frontend/assets/...`，与 GitHub Pages 子路径部署一致。

## 三、预览页包含哪些内容

- 开场动画（齿轮 + 进度百分比 + 版本号浮标，点击任意处跳过）
- 顶部导航：品牌 LOGO + 锚点导航（公告/玩法/下载/活动/留言）+ 账号区（登录前/后）+ 三主题切换（黑夜/白天/护眼）
- 第一屏：公告横向轮播（自动播放/圆点切换/「最后更新于」）
- 玩法介绍（卡片 3D 鼠标倾斜）
- 下载区（推荐版本高亮）
- 功能模块：服务器状态（真实 health 轮询 + 计数动效）/ 在线时长排行 / 规则 FAQ / 活动时间线（点击展开 + 报名占位）/ 玩家留言（localStorage）/ STAFF
- 页脚：社交图标位 + 合规免责声明 + 版权占位
- 全局互动：滚动入场动画、机械工业动态背景、自定义光标（桌面端）

## 四、如何「关掉」预览路由（上线前移除）

预览页与现有框架隔离，移除只需三步：

1. 删除目录：`src/preview/` 与 `docs/preview-code-notes/`。
2. 编辑 `src/router/index.js`：删除
   - `import previewRoutes from '@/preview/router/previewRoutes'`
   - `...previewRoutes,`（在 catch-all 之前的那一行）
3. 卸载预览页专用字体依赖：`npm uninstall @fontsource/pixelify-sans @fontsource/vt323`。

> `src/main.js` 本分支未改动，无需处理（指令已改为组件内局部注册）。

> 完成后 `npm run build` 确认无残留引用即可。
