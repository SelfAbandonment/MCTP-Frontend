## 通用注意事项

- 文字放在英文单引号 `'...'` 里，每项末尾的英文逗号 `,` 不要删。
- 文字里如果要用英文单引号 `'`，改用中文引号「」或 `’`，否则会报错。
- 每个区块最下方灰色的 `TODO-CONTENT：…` / `TODO-BACKEND：…` 提示行会显示在页面上，填好真实内容后可以整段 `<p>…</p>` 删掉。
- 改完运行 `npm run lint:check` 和 `npm run build` 确认没写错。
