# 本轮优化记录（第三轮）

> 在前两轮 24 条建议已落地的基础上，排查出的剩余问题与修复。每条都给出：原因 → 作用 → 改动文件。

## 1. 修复：占位链接点击后跳回首页（真 bug）

- **原因**：站点使用 hash 路由（`#/preview`）。下载区 / 页脚社交 / 活动报名的占位链接写的是 `href="#"`，点击后地址变成 `.../#`，路由解析为 `/`，直接离开预览页回到首页；页脚社交还带 `target="_blank"`，会新开一个首页标签页。审核人一点就"掉出"预览。
- **作用**：数据里的链接改为空字符串表示"待补"；模板中 `href` 为空时 `@click` 拦截默认跳转、加 `aria-disabled`，页脚为空时不加 `target="_blank"`。服主填入真实地址后自动恢复正常跳转，不用改模板。
- **文件**：
  - `src/preview/components/DownloadSection.vue`（`downloads[].href`）
  - `src/preview/components/PreviewFooter.vue`（`socials[].href`）
  - `src/preview/components/EventsTimelineSection.vue`（`RAW_EVENTS[].link`，填入后按钮文案自动变"立即报名"）

## 2. 优化：预览路由懒加载，主站零负担

- **原因**：`previewRoutes.js` 静态 import `PreviewApp.vue`，导致预览页所有组件、GSAP ScrollTrigger、主题 CSS、Google Fonts 请求都打进了主站入口包——访问现有任何页面都会下载它们。
- **作用**：改为 `component: () => import('@/preview/PreviewApp.vue')`。实测 `npm run build`：主站入口 JS 209 kB → 121 kB，CSS 47 kB → 18 kB；直接打开首页时不再请求任何预览页资源或 Google Fonts。
- **文件**：`src/preview/router/previewRoutes.js`

## 3. 优化：`src/main.js` 回退为零改动

- **原因**：之前在 `main.js` 全局注册 `v-reveal` / `v-tilt`，既改动了现有框架，又让主站入口无条件加载 GSAP ScrollTrigger。
- **作用**：在 11 个用到指令的组件里局部注册（`import { reveal as vReveal } ...`），模板写法不变。现在整个分支对现有框架的改动只剩 `src/router/index.js` 里的两行。
- **文件**：`src/main.js`（已 `git checkout` 回 develop 版本）、`src/preview/components/*Section.vue`

## 4. 修复：活动"预告 / 已结束"写死导致数据过期

- **原因**：`type: 'upcoming'` 手写，`2026-10-24` 的活动到 10-31 仍显示"预告"，审核时显得数据不真实。
- **作用**：删掉手写 `type`，按本地日期与今天比较自动计算（活动当天仍算预告）。用本地时区而非 `toISOString()`（UTC），避免北京时间凌晨算错一天。
- **文件**：`src/preview/components/EventsTimelineSection.vue`

## 5. 优化：公告"最后更新于"自动计算

- **原因**：`lastUpdate` 手写固定日期，增删公告后容易忘记同步。
- **作用**：改为 `computed`，从公告列表中取最大日期。
- **文件**：`src/preview/components/AnnouncementSection.vue`

## 6. 修复：离开预览页后 `<html data-theme>` 残留

- **原因**：主题标记挂在全站共用的 `<html>` 上，从预览页跳到其它页面后仍然保留。
- **作用**：themeStore 新增 `clearTheme()`，`PreviewApp` 卸载时调用；用户的主题选择仍在 localStorage 中，下次进入预览页自动恢复。同时给 localStorage 读写加了 try/catch（隐私模式会抛异常导致白屏）。
- **文件**：`src/preview/stores/themeStore.js`、`src/preview/PreviewApp.vue`

## 7. 优化：v-reveal 卸载清理（对应建议 19）

- **原因**：原 `unmounted` 每次都遍历全部 ScrollTrigger（元素多时 O(n²)），且只 kill 触发器、不 kill tween 本身。
- **作用**：`mounted` 时把 tween 存到 `el._revealTween`，卸载时直接销毁该 tween 与它的 ScrollTrigger。
- **文件**：`src/preview/directives/reveal.js`

## 8. Lint 清零（对应建议 18）

- **原因**：仓库其它代码 ESLint 为 0 warning，预览页代码带来 374 条 warning（模板换行/属性换行/void 元素自闭合等纯格式问题），会增加审核摩擦。
- **作用**：`eslint --fix` 自动格式化 `src/preview/`，现在 `npm run lint:check` 全仓 0 error / 0 warning。仅格式变化，无逻辑变化。

## 9. 字体改为本地自托管

- **原因**：Pixelify Sans / VT323 原先从 `fonts.googleapis.com` 加载，国内访问常被阻断或很慢，失败时退回微软雅黑，像素风丢失；审核环境断网时同理。
- **作用**：新增依赖 `@fontsource/pixelify-sans`、`@fontsource/vt323`（均 ^5.3.0，SIL OFL 1.1 可商用），在 `PreviewApp.vue` 引入 Pixelify Sans 400/700 与 VT323 400；删除 `theme.css` 中的 Google Fonts `@import`。字体文件被 Vite 打包成 `dist/assets/*.woff2`，随站点部署；按 unicode-range 拆分，浏览器只下载实际用到的子集（拉丁 400 约 7.7 kB）。字体只在预览页懒加载包中，主站入口 CSS 体积不变（17.93 kB）。
- **文件**：`package.json` / `package-lock.json`（仅新增这两个包）、`src/preview/PreviewApp.vue`、`src/preview/styles/theme.css`
- **验证**：构建产物中已无 `googleapis` 引用；浏览器实测字体请求来自 `/MCTP-Frontend/assets/pixelify-sans-latin-400-normal-*.woff2`，`document.fonts.check('16px "Pixelify Sans"')` 为 true。
- **移除预览页时**：若删除 `src/preview/`，记得同时 `npm uninstall @fontsource/pixelify-sans @fontsource/vt323`。
