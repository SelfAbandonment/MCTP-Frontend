# MCTP Frontend

MCTP API 的前端 Dashboard，基于 Vue 3 + Vite 构建。

## 功能

- 实时 API 健康状态监控（每 30 秒自动刷新）
- API 端点列表
- 技术栈展示
- 快速链接：Swagger UI、ReDoc、GitHub 仓库

## 在线访问

- **Frontend**: https://selfabandonment.github.io/MCTP-Frontend/
- **Backend API**: https://mctp-api.onrender.com
- **Swagger**: https://mctp-api.onrender.com/api/docs/

## 本地开发

```bash
npm install
npm run dev
```

## 部署

推送到 `main` 分支自动触发 GitHub Actions 部署到 GitHub Pages。
